WHAT P_lana IS
----------------------------------------------------------------------------------------------------
The LanA probabilistic language atlas sampled at each contact's fsaverage
position: the fraction of that atlas's subjects whose language network covers
this point. It is an ATLAS PRIOR ABOUT A LOCATION, not a measurement in this
patient. A high value means the contact sits where language cortex usually is;
it does not mean the contact responded to language, and a low value does not
mean it did not. Nothing in this figure is evidence that a cluster IS or IS NOT
language-responsive - only that it does or does not sit where LanA is.

COVERAGE, AND WHY IT IS NOT A DETAIL

  largest disagreement between them   0 (tolerance 0.001)

The tables are written on different dates and round to different precision in
CSV, so they are compared with a tolerance rather than for exact equality, and
only where BOTH have a value - a contact the atlas could not sample is a
coverage difference, not a disagreement about a number.

The missing electrodes are NOT missing at random: the atlas run predates part of
the cohort, so whole patients have no value at all. A cluster drawn mostly from
those patients would look like it sits outside language cortex when in truth it
has not been measured against the atlas. Per-cluster coverage is printed under
every bar in panel A and anything below 70% is marked in red.

THE NULLS, AND WHY THERE ARE TWO
----------------------------------------------------------------------------------------------------
SPATIAL AUTOCORRELATION IS THE WHOLE PROBLEM. A contact and its neighbour 3 mm
along the same shaft have nearly identical P_lana, because a brain map is smooth;
that smoothness inflates any correlation computed against it. The field's answer
is a spatially-constrained null - Alexander-Bloch's spin test for dense surface
maps, variogram-matched surrogates for sparse points.

The sEEG analogue used here is a CIRCULAR SHIFT ALONG EACH SHAFT: every
electrode's cluster and loading are rolled by a random offset within its own
shaft while P_lana stays put. Each shaft's run structure survives exactly - the
same labels in the same runs, in the same order - and only its alignment with the
atlas is broken. This is the null that counts, marked * on the figure.

  shafts                 264
  invariant to a shift   121 (one cluster throughout, so a
                         shift cannot change them; they carry no information
                         about alignment and contribute no randomness)

THE SECOND NULL, KEPT FOR COMPARISON
----------------------------------------------------------------------------------------------------
Contacts on one shaft sit millimetres apart, share a patient, and share an atlas
neighbourhood, so a correlation across ~1400 electrodes has nothing like 1400
degrees of freedom. The weaker null permutes P_lana WITHIN EACH PATIENT: that
keeps each patient's own atlas values and coverage exactly as they are and
breaks only the link between a contact's position and its cluster. A null that
shuffled across patients would also destroy the fact that patients are implanted
in different places, and would be far too easy to beat.

Confidence intervals BOOTSTRAP PATIENTS, not electrodes, for the same reason: an
electrode bootstrap treats contacts on one shaft as independent draws and returns
intervals several times too narrow.

  1000 permutations of EACH null, 1000 bootstraps, patients resampled
  with replacement

Both are reported on the figure and in the table below. Where they disagree, the
spatial smoothness was doing the work and the weaker null was crediting the
clustering for it - which is exactly what a within-patient shuffle cannot see.

PANELS C and B - loading against P_lana (C every electrode, B the rhos ranked)
----------------------------------------------------------------------------------------------------
Spearman rho between an electrode's LOADING on a cluster and its P_lana, across
EVERY electrode with a LanA value - not only the cluster's own members, because
the question is whether belonging more strongly to this cluster goes with sitting
further into language cortex, and that is a statement about all of them.

Spearman, not Pearson: P_lana is a bounded, heavily right-skewed probability and
the loadings are not normal either, so a rank correlation is the honest choice.

THE K CORRELATIONS ARE NOT INDEPENDENT OF EACH OTHER, and this is the easiest
number in the figure to over-read. A convex-NMF loading vector is normalised to
sum to 1, so the K loadings of one electrode live on a simplex: if one cluster's
loading rises with P_lana, the others MUST fall, whatever they are describing.
A negative rho is therefore 'not this cluster' and not 'this cluster avoids
language cortex' - the two are indistinguishable from this panel. Only the
POSITIVE end is interpretable on its own, and even the ranking among negatives is
partly an artefact of how strong the leader is. Verified on synthetic data where
one cluster was planted to track the atlas: every other cluster went negative
without being planted to do anything at all.

The within-patient null does not remove this. It is computed on the same
normalised loadings, so it prices in the simplex for EACH cluster separately -
it says whether that cluster's rho exceeds chance, not whether the K rhos are
mutually consistent.

HOW TO READ THIS FIGURE
----------------------------------------------------------------------------------------------------
P(LanA) is an ATLAS PRIOR about a location - the fraction of LanA's subjects whose language network
covers this point. It is not a measurement in this patient. A cluster high in panel A sits where
language cortex usually is; whether it RESPONDED to language is FIG 1, not this.

Against the SHAFT-SHIFT null, which preserves the spatial smoothness of the atlas, 2 of 8 clusters
sit in more LanA than chance and 1 of 8 correlations pass. Against the weaker within-patient null it
is 1 and 3. Where those differ, the smoothness was doing the work.

The largest |rho| is 0.12. Significance here is nearly free at this sample size; the effect size is
the result.

Only 100% of electrodes have a LanA value, and the missing ones are WHOLE PATIENTS rather than a
random scatter - the atlas run predates part of the cohort. Every cluster is above the coverage
floor here.

The K correlations are NOT independent: loadings sum to 1, so one cluster tracking the atlas forces
the others negative by arithmetic. Only the positive end is interpretable alone.

LanA is left-lateralised and sEEG coverage is not symmetric, so a left-heavy cluster scores higher
for that reason alone. Neither null removes it: it is a property of where a cluster is, not of which
patients it draws on.

WHAT THIS FIGURE DOES NOT SHOW
----------------------------------------------------------------------------------------------------
  - Not evidence of language responsiveness. LanA is a prior about where language
    cortex usually sits, sampled at a coordinate. The response itself is FIG 1.
  - Not corrected for the fact that LanA is left-lateralised and sEEG coverage is
    not symmetric. A cluster that happens to be left-heavy will score higher for
    that reason alone; the within-patient null does not remove it, because it is
    a property of where a cluster is, not of which patients it draws on.
  - Not a statement about K. The clusters are whatever this K produced.
  - The 297 electrodes with no LanA value are excluded from every number here,
    not counted as zero.
