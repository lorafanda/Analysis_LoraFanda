# MOBA 3D brain viewer — setup notes

The MOBA dashboard (Mosaics of Brain Activity) at
`https://lorafanda.github.io/moba.html` renders all clustered electrodes on a
3D fsaverage brain, with live filters for clusters / patients / conditions and
a synced ERSP samples grid.

It needs three things to render:

1. **`outputs/clustering/index.json`** — produced by `lf_cluster_run.fit_and_save`.
   Already there if you've run `210_raw_clustering.ipynb`.
2. **Per-run merged CSV** with x/y/z fsaverage coords joined to labels —
   produced by `252_clustering_recon.ipynb`. Already there if 252 has run.
3. **fsaverage mesh files** at
   `outputs/250_recon/fsaverage/meshes/fsaverage_{lh,rh}.mz3` — generated by
   the script in this folder, run **once**.

## One-time setup: build the brain meshes

From the repo root on the server:

```powershell
cd S:\HumanNeuronLab\ANALYSIS\FLM\Analysis_LoraFanda
python 02_FBM_Clustering/scripts/build_fsaverage_meshes.py
```

The script auto-detects fsaverage in standard places (Bern Reconstruction
folder, `$FREESURFER_HOME/subjects`, `$SUBJECTS_DIR`). If it can't find it,
edit `FSAVERAGE_CANDIDATES` at the top of the script.

It writes 4 files (~5 MB total):

```
outputs/250_recon/fsaverage/meshes/
    fsaverage_lh.mz3        # primary, used by the page
    fsaverage_lh.gii        # fallback
    fsaverage_rh.mz3
    fsaverage_rh.gii
```

Commit and push:

```powershell
git add 02_FBM_Clustering/outputs/250_recon/fsaverage/meshes
git commit -m "fsaverage meshes for MOBA 3D brain viewer"
git push
```

## Verifying it works

After pushing, hard-refresh the website (`Ctrl+Shift+R`):

1. `https://lorafanda.github.io/results.html` → enter `LiLo` → click "🧠 Open
   in MOBA" in the run-picker bar (or visit `moba.html` directly).
2. Pick a run from the dropdown.
3. The 3D brain should render in a few seconds. Rotate with click+drag, zoom
   with scroll, pan with right-click+drag.
4. Hovering an electrode shows a tooltip with patient / contact / condition /
   cluster + silhouette.

## Troubleshooting

If the brain area shows a status message instead of the 3D view, open the
browser DevTools console (F12). Common issues:

| Console message | Cause | Fix |
|---|---|---|
| `Mesh load failed: 404 ... fsaverage_lh.mz3` | Mesh files not committed yet | Run the script above and push |
| `Coords load failed: 404 ... __with_fsaverage.csv` | 252 hasn't run for this run | Run 252 in `02_FBM_Clustering` and push |
| `Niivue is not defined` | CDN fetch failed | Check network / try again later |
| `index.json not found` | Run 210 first to populate the manifest | |

## How to disable / revert

The MOBA page is purely additive — `results.html` still has the existing
Clusters tab with recon-image strip. To hide MOBA entirely:

```powershell
git revert <COMMIT_HASH_OF_MOBA_INTRODUCTION>
```

Or just remove the "🧠 Open in MOBA" button from `results.html` — `moba.html`
still exists at the URL but nothing on the main site links to it.
